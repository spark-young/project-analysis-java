| 项 | 值 |
|---|---|
| 定位 | 内网 Java 工程静态分析 Web 工具（ASM 读字节码，不加载不执行；零出站；默认只绑 127.0.0.1:8080） |
| 技术栈 | Spring Boot **2.7.18** / **Java 11**（须 JDK）/ Maven 3.6.3 / ASM 9.7 / POI 5.2.5 / JGit **锁死 5.1.3** |
| 前端 | 原生 HTML/JS/CSS，**无构建工具**，`<script>` 直载 |
| 回归基线 | `mvn -B clean test -DforkCount=0` → **193 用例 / 15 失败**（15 项**全部** ENV-01，见 §6） |
| 前端契约测试 | `node src/test/js/contract.test.js` → **132/132**；已纳入 `mvn test`（`FrontendContractTest`） |

**项目硬约束（改代码前必读）**
1. **JGit 版本不可改**（内网私服只有 5.1.3）。全仓唯一 JGit 使用者是 `GitCloneService.clone()`，**生产不调用它**（生产走 git CLI），但 **4 个测试类依赖它** → 不要轻率移除依赖；CVE-2023-4759 已由 `core.symlinks=false`（OPT-16）兜底。
2. **本地导入一律不编译**（产品约定），编译只发生在 Git 场景。
3. 项目级数据目录必须走 `CallgraphPaths.projectDataDir()`，禁止自己拼 `.callgraph`。
4. 默认只绑 127.0.0.1；对外需显式 `--server.address=0.0.0.0` 或 `CG_ADDR`。
5. 前端改静态资源后**必须提升 `index.html` 的 `?v=`**。
6. 方法签名统一 `全限定类名#方法名(参数短名列表)`，构造器 `#<init>`；前后端共用（`Sig`/`MethodKey`），不要各写一套。
7. 文件保持 **UTF-8 无 BOM**；`start.bat` 必须 **GBK + CRLF**。

**已确立的簇间纪律（后续簇必须遵守）**
1. **只搬不改**：函数体逐行照搬，零行为变化；发现"搬动必须改行为"→ 停下报告。
2. **一簇一 commit**，只含源码文件；便于单独回滚。
3. **共享状态最小化**：仅跨簇使用才进 `App.state`（含写入方/读取方/**清零归属**注释）；模块私有优先（如 `entryItems`、`gitSwitchTimer`）。
4. **句柄类状态**（定时器）必须写清 `clearInterval` 责任归属（唯一清理点、可否重复、重入处置）。
5. **getter hook 活读**（读 app.js 闭包 let 的跨簇读取）：hook 必须是捕获变量绑定的箭头函数，**调用点在函数体内执行期**——禁止 init 时求值存快照。
6. **init 注入顺序 = 原 IIFE 行号顺序**（`els` 在 ui.js 一次性构建，任何用 els 的 init 必须在其后）。

## 6. 环境与操作须知（本机踩坑汇总）

| 坑 | 应对 |
|---|---|
| **Bash 工具 PATH 坏**（`ls`/`dirname` 均 command not found） | 一律用 **PowerShell**；需要输出时 `命令 2>&1 \| Out-File <绝对路径> -Encoding utf8` 再读文件 |
| **本机 git CLI 不可用**（ENV-01） | `git-upload-pack` 拉不起（加 PATH 无效）→ 15 项 git 测试失败**属环境非产品缺陷**；本地 git 命令可用**全路径** `X:\Git\Git\cmd\git.exe` |
| `mvn test` 需 `-DforkCount=0` | 否则 WMIC 阻塞 Surefire fork |
| **无法删除文件**（safe-delete 拦截） | 仓库根已积累大量 `_tmp_*`/`_opt*` 临时文件，**需手工清理** |
| 目录级 `git add` 会误吞临时文件 | **一律用精确文件名 add**（曾误入库 `_lines.txt`，已用 `9fa4571` 移除） |
| PS 5.1 here-string 传中文 commit message 会**双重编码污染** | 用 `git commit -F <UTF-8 文件>` |
| 同一文件**并行 Edit 会互相覆盖** | 同文件多处编辑必须**串行** |
| 前端改资源忘升 `?v=` | 每次同步改 `index.html`，列入提交前检查单 |
